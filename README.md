Продвинутый плагин RTPF 1.21.X
Асинхронная подгрузка чанков при телепортации с защитой от появления в не безопасном месте и настраиваемым кулдауном.

Команды игроков:
/rtp - Рандомная телепортация
/rtp reload - Перезагрузка конфигов

Разрешения:
-    rtp.use
-    rtp.bypass.countdown
-    rtp.admin

Канал разработчика в тг - https://t.me/fell1cs_studio
Полная поддержка форматирования MiniMessage
